# MagneticFieldCode_Axisymmetric
Computes the 2D magnetic fields and A_phi of an arbitrary setup of planar axisymmetric coils

Functions:
Contains all the important functions that make up this repo

Examples:
This folder contains 4 detailed examples of how to use the functions in this repo to solve for the magnetic fields in axisymmetric devices


contained_code folder has is a stand alone folder that has everything to run Vis_opt.m, the visualization of the multi-modal generative model.  You will need to download, ml_surrogat.mat, the data generated by the ML at https://www.dropbox.com/scl/fi/uwg6onbas3bj79ekspsqu/ml_surrogate.mat?rlkey=m3jdicdp4ilzq8merokru2ddu&dl=0.  This mat file should be added to the contained_code for it to run.
